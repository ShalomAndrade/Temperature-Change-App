# Reactive Temperature Converter

A lightweight, cross-platform desktop application that provides real-time temperature conversions. Built with C# and Avalonia UI, this app instantly calculates and updates the corresponding Fahrenheit or Celsius value the moment a user types a number, providing a seamless and reactive user experience.

## Features

* **Real-Time Conversion:** Instantly converts between Celsius and Fahrenheit as values are entered—no "Calculate" button required.
* **Two-Way Binding:** Powered by a reactive MVVM (Model-View-ViewModel) architecture to keep the UI and data perfectly in sync.
* **Cross-Platform:** Runs smoothly on macOS (including Apple Silicon), Windows, and Linux.
* **Clean UI:** A simple, intuitive interface featuring corner-radius styling and clean layout grids.

## Tech Stack

* **Language:** C#
* **Framework:** Avalonia UI / .NET
* **Architecture:** MVVM (Model-View-ViewModel)
